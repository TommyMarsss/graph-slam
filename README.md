# 简化 2D 位姿图优化与错误回环诊断（Go 标准库）

给定一系列里程计相对位姿约束和若干回环检测约束，用自实现的非线性最小二乘
（Levenberg–Marquardt）修正累积漂移，并：

1. 正确处理角度分量在 ±π 处的环绕（wrap / winding）问题；
2. 定位被错误注入的回环约束（两个实际不相邻的位姿被误判为同一地点）；
3. 识别“数值上收敛、几何上荒谬”的局部最优解（折叠、自穿越），
   而不是笼统报告收敛成功或失败；
4. 生成**单一自包含静态 HTML**（数据与原生 JS/canvas 全部内嵌，
   无服务、无第三方库、无框架），对比优化前后轨迹并高亮错误回环；
5. 提供覆盖以上四点的自动化测试。

仅依赖 Go 标准库；前端仅使用原生 HTML/CSS/JavaScript 与 `<canvas>`。

## 运行

```bash
go run .                 # 跑三个内置场景，生成 report.html 并打印诊断
go test ./...            # 自动化测试
go test -v ./...         # 查看每个用例
```

然后用浏览器直接打开生成的 `report.html`（双击或
`file://.../report.html` 即可，不需要任何服务器）。

## 位姿图模型

节点为 2D 刚体位姿 `p_i = (x_i, y_i, θ_i)`；每条约束是节点 i→j 的
相对位姿测量 `Z_ij = (t_x, t_y, θ_ij)` 与对角信息矩阵 `Σ⁻¹`：

```
e_ij = [ R(θ_i)ᵀ(p_j − p_i) − t_ij ]
       [ wrap(θ_j − θ_i − θ_ij)    ]
cost = ½ Σ_edges  e_ijᵀ Σ_ij⁻¹ e_ij
```

- 里程计约束连接相邻节点（`i, i+1`）；回环约束连接任意两个节点。
- 节点 0 固定（不进入自由度），消除整体平移/旋转的规范自由度。

### 角度环绕（关键点）

角度是一维流形（圆周）上的量，不是普通实数：

- **残差**中角度项必须先 `wrap` 到 `(-π, π]`。否则在 `θ = ±π`
  边界，物理上只差 0.02 rad 的两个角度，未 wrap 的误差会从
  `+π−ε` 跳到 `−π+ε`，梯度方向整体反转，优化被推离真值。
- **雅可比**角度行恒为 `∂e_θ/∂θ_i = −1, ∂e_θ/∂θ_j = +1`
  （流形上的局部增量），与状态是否跨越 ±π 无关；平移两行含
  `R(θ_i)` 的解析导数。
- 每次状态更新后对 `θ` 重新 wrap，使状态始终位于主值区间。

`TestJacobianAtWrapBoundary` 在 `θ_i = 3.05, θ_j = −3.05`
（未 wrap 误差 −6.15 rad，wrap 后 +0.133 rad）配置下，
把解析雅可比与中心差分数值雅可逐一比对；
`TestWrapBoundaryOptimizerDirection` 验证从 `+π−ε` 与 `−π+ε`
两种等价表示出发优化到同一解。

## 优化算法：为什么选 LM

残差对状态非线性（含旋转矩阵与角度差），问题规模小（几十个节点 × 3 自由度），
故在每步把残差线性化，解正规方程：

```
(Jᵀ W J + λ·diag(Jᵀ W J)) δ = −Jᵀ W e
```

- 纯 Gauss–Newton（λ=0）在初值差时步长过激、容易发散或跨过解；
- 梯度下降类一阶方法在接近解时收敛太慢。
- LM 用信赖域式的阻尼 λ 在两者间切换：代价下降则接受并减小 λ，
  拒绝则增大 λ。本实现对 SPD 失败（极端阻尼下）也有保护。
- 正规方程用自实现的稠密 Cholesky（`A = LLᵀ`，前代+回代）求解。
- 诊断阶段额外跑一次带 **Huber 鲁棒核**（k=2，白化残差尺度）的 LM，
  降低单条坏约束对“其他约束残差评估”的污染。

## 错误回环定位

对每条回环约束收集三类证据：

1. **鲁棒残差** `r = √χ²`：Huber 鲁棒优化后该回环自身仍拟合不上的程度
   （正确回环 r≈0.3~1，错误回环 r≈1e3）；
2. **leave-one-out 自身 χ²**：删除该回环后，用其余约束重新优化，
   再在该解上计算它自己的 χ²。错误测量在“没有它参与”的解上必然
   严重不符（本场景 ≈1.8e6），正确回环则很小；
3. **代价影响**：基准代价 − 删除后其余约束的代价，量化它在多大程度上
   强迫全图迁就它。

门控：`r > 0.5 且 leave-one-out χ² > 1` 即判定为错误回环，
并按综合可疑度排序输出。leave-one-out χ² 只作门控、不进排序分数，
因为删除好回环后坏回环仍会把该值推高，直接加和会污染排序。

## 局部最优检测依据

非线性优化的 `status=converged` 只表示步长/代价下降满足容差，
**不表示解在物理/几何上合理**。本项目在无错误回环时做事后几何健全性检查：

1. **非相邻轨迹段自穿越计数**：平面刚体的连续运动轨迹不应自交，
   出现严格线段相交即说明路径折叠；
2. **里程计残差畸形**：最大平移残差/该边测量长度 > 35%，
   或最大角度残差 > 0.8 rad（≈46°）。正常收敛时残差应均匀趋零，
   残差集中在少数边是折叠/翻转驻点的典型特征。

内置的 `local_min` 场景展示了一个真实的角度环绕陷阱：把后半段
真值轨迹绕中心翻转 180° 作为初值，全部约束精确无误，但该初值处于
错误的**环绕数（winding number）分支**——闭合链总转角需要 2π 的跳变，
而每步 wrap 到 `(−π,π]` 无法表达这种跳变。LM 收敛到一个：

- 每条里程计边**平移残差恰好为 0**；
- 总转角 2π 被均摊为每条边 2π/48 ≈ 0.131 rad 的恒定角度残差；
- 轨迹自交 2 处、与真值最大偏差约 17m；

的驻点，优化器自身报告 `converged`。本系统将其标记为
`local_minimum` 并明确说明“这不是收敛失败，而是收敛到了几何上
不合理的驻点”。注意：这与错误回环有本质区别——该场景中回环
`loop-good` 是正确的，不会被误判。

## 三个内置场景

| 场景 | 构造 | 期望诊断 |
|---|---|---|
| `correct` | 12m×12m 矩形（48 节点），里程计小噪声 + 真实首尾回环，里程计递推初值 | `ok`，9 次迭代，代价 ~1.7 |
| `bad_loop` | 同上，额外注入 `loop-BAD`：底边节点 3 与顶边节点 33（相距 ~12m）被误判为同一地点 | `bad_loop`，定位 `loop-BAD` |
| `local_min` | 约束全部精确，初值把节点 12..47 绕中心翻转 180° | `local_minimum`，2 处自交 |

## 测试

```
go test -v ./...
```

- `TestCorrectLoop_MonotonicCostDecrease`：正确回环下被接受迭代的
  代价严格单调下降、最终代价远低于初值、不触发任何告警；
- `TestBadLoop_IsLocated`：错误回环被定位且可疑度排名第一，
  正确回环不受牵连，删除错误回环后其余约束代价接近零；
- `TestWrapAngleBoundaries` / `TestJacobianAtWrapBoundary` /
  `TestWrapBoundaryOptimizerDirection`：wrap 主值区间约定、
  ±π 边界解析雅可比对数值雅可比、边界两侧等价表示收敛一致；
- `TestLocalMinimum_IsDetectedNotReportedAsNormal`：LM 报告收敛，
  但诊断为 `local_minimum`（自交、严重偏离真值、2π/N 均摊角度残差），
  且正确回环不被误判；
- `TestReportSelfContained`：报告为无外部依赖的单一 HTML，
  内嵌数据与 canvas 绘图逻辑。
