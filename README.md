# 简化 2D 位姿图优化系统（graph-slam）

仅依赖 **Go 标准库**实现的 SE(2) 位姿图非线性最小二乘优化，用于研究两类典型失效：

1. **错误回环约束**（perceptual aliasing）对优化结果的破坏性影响，并自动定位是哪一条回环导致了轨迹畸变；
2. **局部最优陷阱**：初值严重失准时，LM 数值上"收敛"却停在几何荒谬的驻点，需要独立于代价的几何判据加以识别，并通过多起点优化恢复。

运行演示后会生成一个**完全自包含的静态 HTML 报告**（数据内嵌、原生 SVG/JavaScript、无任何第三方库、无需服务器）。

## 快速开始

```bash
go test ./...                 # 全部自动化测试
go run ./cmd/demo report.html # 生成并在浏览器打开 report.html
open report.html
```

演示依次运行三个场景并写入同一张报告：

| 场景 | 目的 | 预期结果 |
|---|---|---|
| 割草机往返扫描（正确回环） | 漂移修正、误差单调下降 | χ² 227.8 → 7.9，结局可信，无错误回环 |
| 割草机往返扫描（注入错误回环） | 错误回环破坏与定位 | 轨迹被拽歪、出现自穿越；唯一定位注入边 #59 |
| 闭合圆环（8 字形坏初值） | 局部最优陷阱检测与恢复 | 坏初值困在双圈重合驻点（χ²/边≈870，16 处几何问题），多起点选到 χ²≈0.44 的正确解 |

## 一、位姿图模型

- **状态**：N 个节点位姿 `x_i = (X_i, Y_i, θ_i)`，θ 为弧度。
- **边约束**：每条边给出相对测量 `z_ij = (dx, dy, dθ)`，表示在节点 i 机体坐标系下观察到的节点 j：

  ```
  (dx, dy)ᵀ = R(-θ_i)·(p_j - p_i),  dθ = Wrap(θ_j - θ_i)
  ```

  以及对角信息矩阵 `Ω = diag(σ_xy⁻², σ_xy⁻², σ_θ⁻²)`。
- **代价**（高斯形式）：

  ```
  E(x) = ½ Σ_k e_kᵀ Ω_k e_k,  e_k = h(x_i,x_j) - z_k
  ```

  可选 Huber 鲁棒核 `w(r)=min(1, δ/r)`；错误回环定位默认关闭鲁棒核，
  使"纯高斯残差"的诊断证据不受核权重遮蔽。
- **全局自由度**：节点 0 以强先验 `1e10·I` 锚定，固定全局平移与旋转。

## 二、优化算法：为什么是 Levenberg–Marquardt

非线性最小二乘在当前解处线性化得到 Gauss-Newton 法方程：

```
(H + λ·diagH)·δx = -b,  H = Σ JᵀΩJ,  b = Σ JᵀΩe
```

- 纯 **Gauss-Newton** 步在初值差、强非线性时可能越过合理区域使代价上升；
- **LM** 通过阻尼 λ 在 GN（λ→0）与最速下降（λ 大）之间连续切换，
  并在本实现中做**带回退的自适应线搜索**：代价不下降就 λ×10 重试（最多 20 次），
  接受后 λ×0.5。这保证被接受的每一步 χ² 严格不增。
- 3N×3N 法方程用**自研稠密 Cholesky**（`A=LLᵀ` + 前代/回代）求解，
  非正定时增大阻尼重试，不使用任何第三方线性代数库。
- 收敛判据：梯度范数、步长范数阈值，或找不到下降方向（驻点）。

### 角度环绕的正确处理（关键点）

角度定义在流形 S¹ 上，代价必须使用**最短弧残差**：

```
e_θ = Wrap( Wrap(θ_j - θ_i) - z_θ ) ∈ (-π, π]
```

若不做归一化，真实误差只有 0.05 rad 时原始差值可能是 `2π-0.05`，
二次代价与梯度会把角度朝"绕远一整圈"的方向拉动，优化方向完全相反。

实现要点：**环绕只影响残差取值，不修改导数**。在被选中的最短弧分支内
`e_θ` 仍是线性函数，雅可比角度行恒为 `∂e_θ/∂θ_i = -1, ∂e_θ/∂θ_j = +1`；
平移-角度耦合项 `(p_y, -p_x)` 也由当前分支下的相对平移给出。
`TestAngleWrappingJacobian` 在 ±π 边界两侧用中心有限差分逐项核对了
全部 3×6 个雅可比元素，`TestWrappingGradientDirection` 验证下降步指向最短弧。

## 三、错误回环定位：留一法的"真凶/受害者"判别

错误回环（两个实际相距很远的位姿被误判为同一地点）会像一根错误的拉索，
把整条优化轨迹拽向不可能的形状。但只看"哪条边优化后残差大"会冤枉好边：
真凶扭曲全图后，**其他正确回环也会被迫产生大残差**（受害者）。

因此对每条回环边 k 做**留一法（leave-one-out）**重优化，并要求三条证据同时成立：

1. **自身残差**：k 在完整图解上归一化残差 `√(eᵀΩe) > 3σ`；
2. **因果证据（核心）**：剔除 k 重新优化后，**其余所有回环**的最大残差降到 2σ 以下
   —— 冲突随 k 的消失而消失，证明 k 是冲突源；剔除无辜边时真凶仍在，
   至少一条回环（真凶自己）残差依然很大；
3. **代价证据**：剔除 k 使全图代价显著下降（默认 >2%）。

场景 2 中注入边 #59 自身残差 87.5σ，剔除它后其余回环最大残差仅 0.71σ、
代价下降 11088；而 9 条正确回环虽然在完整图上残差高达 20–66σ，
剔除任一条后其余回环最大残差仍有 65–87σ，因此全部被宣告无罪。
结果是**唯一定位**，报告轨迹图中该边以红色加粗虚线和 `!` 标记高亮。

## 四、局部最优陷阱：几何检测与三分类

LM 的 `Converged=true` 只表示找到了梯度驻点，不表示解正确。
SE(2) 角度环绕与闭合约束使问题非凸，存在几何荒谬的驻点。
本系统把结局显式分成三类（`ClassifyOutcome`），而不是"成功/失败"一刀切：

| 结局 | 条件 |
|---|---|
| `not-converged` | 迭代耗尽等，未到驻点 |
| `local-minimum-trap` | 已到驻点，但几何不可信 **或** χ²/边系统性过大（>25，约每分量 5σ） |
| `converged-ok` | 已到驻点，几何合理且残差可信 |

**几何先验**（独立于代价值）：

- **self-intersection**：时间上不相邻的轨迹段严格相交（平滑里程计轨迹不可能自穿越）；
- **node-coincidence**：时间上相距 ≥3 个节点的位姿几乎重合（<5% 中位步长），
  登记在 `KnownRevisits` 中的真实重访（如合法回环连接点）予以豁免；
- **pose-jump**：相邻节点间距超过中位步长 4 倍（位姿突变）。

演示场景 3 是经典的闭合环陷阱：真值为半径 5 的大圆，含闭合回环 N-1↔0；
8 字形坏初值（两个半径 2.5 的小圆，总周长与大圆相等）使里程计链可以很好满足，
整条链却锁死在双圈重合的盆地，唯一闭合边以巨大残差顶着轨迹，
GN 步找不到下降方向。此时优化器报告"到达驻点"，但几何检测给出
15 处异常重合 + 1 处自穿越、χ²/边≈870，正确判定为陷阱。

**恢复手段——多起点优化**：从链式、折叠、扰动等差异显著的初值分别求解，
用几何检测给每个结果分类，在所有"几何可信"的结果里取代价最低者。
陷阱场景中两个好初值都到达 χ²≈0.44 的正确解并被选中。

## 五、报告页面

`WriteHTML` 输出单个 HTML 文件：全部数据 JSON 内嵌于 `<script>`，
图形为手写 SVG（轨迹、回环边、自穿越标记、对数纵轴 χ² 收敛曲线），
支持图层开关、节点/回环悬停详情、回环诊断表、多起点对照表、深浅色自适应。
不发起任何网络请求，不引用任何框架/图形库/字体。

## 测试覆盖（`graphslam/solver_test.go`）

- `TestWrapAngle`：±π 边界与周期的环绕归一化；
- `TestAngleWrappingJacobian`：±π 两侧解析雅可比与有限差分逐项一致（18 个元素）；
- `TestWrappingGradientDirection`：边界处下降步指向最短弧；
- `TestMonotonicChi2CorrectLoops`：正确回环下 χ² 逐次单调不增、显著下降、贴近真值、无误报；
- `TestBadLoopLocated`：注入边被唯一定位、剔除后冲突消失、正确回环全部无罪；
- `TestLocalOptTrapDetected`：8 字形陷阱被判为 trap 而非正常收敛，同一图好初值判为 ok（防误报），多起点能恢复；
- `TestCholeskySolvesKnownSystem` / `TestHuberWeight`：线性求解器与鲁棒核单元测试。

## 局限与可扩展点

- Cholesky 为稠密实现，规模到数百节点流畅；更大规模应换稀疏 Cholesky/PCG（接口不变）。
- 几何阈值（步长倍数、重合容差）针对平滑地面机器人轨迹；退化运动（原地旋转为主）需另行标定。
- 留一法为单条坏边设计；多条互相强化的坏边可迭代地"定位→剔除→重优化"。
